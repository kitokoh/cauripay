# ADR-002 — Le cœur produit est la plateforme wallet GOURSI

- **Statut** : Adoptée · **Date** : 2026-08-14 · **Décideur** : kitokoh
- **Contexte** : repo contient un MVP agrégateur v0.1 ; le backlog GOURSI décrit une plateforme wallet.
- **Décision** : la cible produit est la plateforme wallet GOURSI ; l'agrégateur v0.1 passe en
  historique (`legacy/`), plus de fonctionnalités.
- **Conséquences** : architecture §1.1 et backlog GOURSI font foi ; ledger Java = cœur comptable.
