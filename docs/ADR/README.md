# ADR — Décisions d'architecture

Une ADR (Architecture Decision Record) documente une décision structurante au format
**Contexte / Décision / Conséquences** (RFC 2119 : *doit*, *ne doit pas*).

Règles :
- Une ADR adoptée ne se modifie que par une **nouvelle** ADR.
- Chaque ADR est validée par le propriétaire du projet (commentaire sur l'issue GOURSI-ADR1).
