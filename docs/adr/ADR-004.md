# ADR-004 — Convention de ports & nommage des services

- **Statut** : Accepté (2026-08-14)
- **Décideur** : Responsable projet
- **Issue** : GOURSI-001 (#138) et bootstraps de services

## Décision

| Port | Service | Constante d'environnement |
|---|---|---|
| 3000 | api-core | `API_CORE_PORT` |
| 3001 | web-admin | `WEB_ADMIN_PORT` |
| 3002 | web-business | `WEB_BUSINESS_PORT` |
| 3010 | ledger-service | `LEDGER_PORT` |
| 3020 | business-service | `BUSINESS_PORT` |
| 3030 | kyc-service | `KYC_PORT` |
| 3040 | aml-service | `AML_PORT` |
| 3050 | notification-service | `NOTIFICATION_PORT` |
| 3060 | ussd-service | `USSD_PORT` |
| 3070 | reconciliation-service | `RECONCILIATION_PORT` |
| 3080 | developer-gateway | `DEV_GATEWAY_PORT` |
| 9090 / 3000 | Prometheus / Grafana | — |

Règles :
- **3000–3010 réservés** à l'axe critique (api-core, web apps) ; **3010–3090** aux services internes.
- Un nouveau service reprend la plage libre suivante (ex. 3090) et **déclare sa constante de port dans
  .env.example** (GOURSI-001b).
- Les services internes n'exposent **jamais** de port public : réseau Docker interne + `X-Service-Key`.

## Nommage

- Dépôt : `services/<nom>-service` (NestJS) / `services/ledger-service` (Java).
- Packages : `packages/<kebab-case>` (npm) — scope npm `@goursi/*`.
- Apps : `apps/web-*` (Next.js), `apps/mobile-*` (Flutter).
- Base de données : une base par service (`goursi_<service>`) ; schéma ledger isolé (`ledger`).
